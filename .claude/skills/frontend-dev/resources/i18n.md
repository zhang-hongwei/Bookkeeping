# Internationalization (i18n)

Use react-i18next for all text content.

## Basic Usage

```tsx
import { useTranslation } from 'react-i18next';

export const MyComponent = () => {
  const { t } = useTranslation();

  return (
    <Box>
      <Typography>{t('welcome.title')}</Typography>
      <Typography>{t('welcome.description')}</Typography>
      <Button>{t('common.submit')}</Button>
    </Box>
  );
};
```

## Translation Files

Store translations in `public/locales/{lang}/`:

```
public/locales/
├── en/
│   ├── common.json
│   └── feature.json
├── zh/
│   ├── common.json
│   └── feature.json
```

Example `common.json`:

```json
{
  "welcome": {
    "title": "Welcome",
    "description": "Get started with our platform"
  },
  "common": {
    "submit": "Submit",
    "cancel": "Cancel",
    "save": "Save"
  }
}
```

## With Variables

```tsx
// Translation file
{
  "greeting": "Hello, {{name}}!",
  "items": "You have {{count}} items"
}

// Component
<Typography>{t('greeting', { name: 'John' })}</Typography>
<Typography>{t('items', { count: 5 })}</Typography>
```

## Pluralization

```json
{
  "item_one": "{{count}} item",
  "item_other": "{{count}} items"
}
```

```tsx
<Typography>{t('item', { count: 1 })}</Typography>  // "1 item"
<Typography>{t('item', { count: 5 })}</Typography>  // "5 items"
```

## Namespace

```tsx
// Use specific namespace
const { t } = useTranslation('feature');
<Typography>{t('title')}</Typography>

// Multiple namespaces
const { t } = useTranslation(['common', 'feature']);
<Button>{t('common:submit')}</Button>
```

## Language Switcher

```tsx
import { useTranslation } from 'react-i18next';
import { Select } from '@/components/ui';

export const LanguageSwitcher = () => {
  const { i18n } = useTranslation();

  return (
    <Select
      value={i18n.language}
      onChange={(lang) => i18n.changeLanguage(lang)}
      options={[
        { label: 'English', value: 'en' },
        { label: 'Chinese', value: 'zh' },
      ]}
    />
  );
};
```

## Best Practices

1. **Never hardcode text**: Always use `t()` for user-facing text
2. **Organize by feature**: Use namespaces for different features
3. **Consistent keys**: Use dot notation (`feature.section.item`)
4. **Default language**: English as fallback
5. **Type safety**: Use TypeScript for translation keys if needed
